### Bienvenue sur la page GitHub Sponsors des Éditions Hélène Voyer 👋

**Éditions Hélène Voyer** est une maison d'édition indépendante québécoise dédiée à l'apprentissage du génie logiciel, à la formation technique et au mentorat de la relève en technologies de l'information.

#### 🎯 Notre mission open source
La transition entre le code académique et le développement logiciel d'entreprise comporte un fossé important. Pour aider les étudiants, les stagiaires et les développeurs juniors à franchir cette étape avec succès, nous mettons à disposition de la communauté du contenu ouvert, documenté et rigoureusement conçu selon les standards de l'industrie :

* **Architectures et patrons de conception concrets :** Dépôts d'exemples d'applications de référence (Java, Spring Boot, etc.) sous licence libre (MIT).
* **Parcours de refactorisation documentés :** Progression pas-à-pas illustrant comment transformer du code fonctionnel mais fragile en solutions robustes, testables et maintenables.
* **Bonnes pratiques d'ingénierie :** Documentation wiki, suites de tests unitaires et intégrés, gestion de versions et flux de travail Git professionnels.
* **Ressources techniques en français :** Valorisation d'une littérature technique de qualité dans la francophonie.

#### 💡 À quoi servent vos contributions ?
Le soutien collecté via GitHub Sponsors permet directement de :
1. **Pérenniser la maintenance** des dépôts publics, la mise à jour des dépendances et la résolution des signalements.
2. **Développer de nouveaux modules didactiques** et cas pratiques réutilisables.
3. **Financer les outils et infrastructures** nécessaires à la création de contenus éducatifs en accès libre.

Que vous soyez un développeur individuel souhaitant soutenir le partage de connaissances ou une entreprise désireuse d'investir dans la préparation technique de ses futurs talents, votre contribution fait une réelle différence.

Merci pour votre soutien à la relève et à l'ingénierie logicielle !

# D'étudiante à professionnelle TI — Exemples de code
Bienvenue sur le dépôt officiel des exemples de code et des projets pratiques accompagnant le livre « D'étudiante à professionnelle TI » par Hélène Voyer.
Ce dépôt a été conçu pour guider la transition du monde académique vers le milieu professionnel en illustrant les standards, architectures et bonnes pratiques attendus dans une équipe de développement moderne.

📌 Objectif du dépôt
 * Illustrer pas à pas les concepts abordés dans chaque chapitre.
 * Montrer l'évolution d'un code : d'une solution étudiante naïve vers une architecture logicielle robuste, maintenable et testable.
 * Fournir une base de code prête à exécuter pour expérimenter et pratiquer.
🛠 Prérequis et environnement technique
Avant de commencer, assurez-vous d'avoir installé :
 * Java JDK : version 21 LTS
 * Outil de build : Maven 3.9+ 
 * IDE recommandé : VS Code avec le pack d'extensions Java
 * Git : pour cloner et naviguer dans les branches

🚀 Démarrage rapide
 * Cloner le dépôt :
   git clone https://github.com/votre-utilisateur/ExemplesManuscrit.git
cd ExemplesManuscrit

 * Compiler le projet :
   ./mvn clean compile

 * Lancer les tests :
   ./mvn test
