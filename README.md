# D'étudiante à professionnelle TI — Exemples de code
Bienvenue sur le dépôt officiel des exemples de code et des projets pratiques accompagnant le livre « D'étudiante à professionnelle TI » par Hélène Voyer.
Ce dépôt a été conçu pour guider la transition du monde académique vers le milieu professionnel en illustrant les standards, architectures et bonnes pratiques attendus dans une équipe de développement moderne.

📌 Objectif du dépôt
 * Illustrer pas à pas les concepts abordés dans chaque chapitre.
 * Montrer l'évolution d'un code : d'une solution étudiante naïve vers une architecture logicielle robuste, maintenable et testable.
 * Fournir une base de code prête à exécuter pour expérimenter et pratiquer.
🛠 Prérequis et environnement technique
Avant de commencer, assurez-vous d'avoir installé :
 * Java JDK : version 21 LTS
 * Outil de build : Maven 3.9+ 
 * IDE recommandé : VS Code avec le pack d'extensions Java
 * Git : pour cloner et naviguer dans les branches

📂 Structure du projet

chapitre-2/methodes-statiques

🚀 Démarrage rapide
 * Cloner le dépôt :
   git clone https://github.com/votre-utilisateur/ExemplesManuscrit.git
cd ExemplesManuscrit

 * Compiler le projet :
   ./mvn clean compile

 * Lancer les tests :
   ./mvn test
